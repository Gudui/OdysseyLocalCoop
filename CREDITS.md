# Credits

Odyssey Local Co-op is developed and maintained by [Gudui](https://github.com/Gudui).

The project builds on the work of these open-source projects and their contributors:

- [ExLaunch](https://github.com/shadowninja108/exlaunch), by shadowninja108 and contributors, provides the executable patching framework and build foundation.
- [Super Mario Odyssey Online](https://github.com/CraftyBoss/SuperMarioOdysseyOnline), by CraftyBoss and contributors, informed the costume/model resource-loading approach. No networking code or release binaries from that project are included.
- [OdysseyDecomp](https://github.com/MonsterDruide1/OdysseyDecomp) and its contributors provided function, type, and game-structure research used during development. Its source tree is not included in this repository.
- [sead](https://github.com/open-ead/sead) contributors documented Nintendo's system-library interfaces used by related reverse-engineering work. Its source tree is not included in this repository.
