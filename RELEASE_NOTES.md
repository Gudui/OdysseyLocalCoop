# v0.1.0-alpha.5 release notes

## Highlights

- Start and end full-player co-op directly through Odyssey's pause-menu `Two Players` and `One Player` actions.
- Start normally with P1 only; P2 and the co-op HUD now exist only while co-op mode is active.
- Switch repeatedly between one and two players without stale P2 health or HUD state.
- P2 can open and navigate the shared map, confirm checkpoint warps, and interact with ordinary NPC conversations.

Native Mario-and-Cappy Separate Play remains disabled internally so both full player actors keep their independent controller routing.
